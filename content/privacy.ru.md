На этом сайте нет учётных записей, форм, комментариев и рекламы, и он не устанавливает cookie. Он ничего не сохраняет в вашем браузере.

## Хостинг

Сайт размещён на GitHub Pages. GitHub в целях безопасности записывает IP-адрес каждого посетителя; подробнее в [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Статистика

Для подсчёта посещений и измерения скорости загрузки страниц я использую Cloudflare Web Analytics. По данным Cloudflare, сервис не использует cookie и другое хранилище браузера и не идентифицирует посетителей по IP-адресу или браузеру. Я вижу только сводные цифры, например посещения и просмотры по страницам.

## Видео

Таймлапс-видео загружаются из хранилища Cloudflare R2, поэтому при их воспроизведении запрос получает Cloudflare. Подробнее в [политике конфиденциальности Cloudflare](https://www.cloudflare.com/privacypolicy/).

## Ссылки

Ссылки на AstroBin, Instagram, Facebook, Pinterest и другие сайты ведут на сервисы с собственными политиками конфиденциальности.
