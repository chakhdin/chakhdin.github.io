This site has no accounts, no forms, no comments and no advertising, and it sets no cookies. It doesn't store anything in your browser.

## Hosting

The site is hosted on GitHub Pages. GitHub logs the IP address of every visitor for security purposes; see the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Statistics

I use Cloudflare Web Analytics to count visits and measure how fast the pages load. According to Cloudflare, it uses no cookies or other browser storage and does not fingerprint visitors by their IP address or browser. I only see aggregate figures, such as visits and page views per page.

## Videos

The time-lapse videos are delivered from Cloudflare R2 storage, so Cloudflare receives the request when you play one. See the [Cloudflare Privacy Policy](https://www.cloudflare.com/privacypolicy/).

## Links

Links to AstroBin, Instagram, Facebook, Pinterest and other sites take you to services with their own privacy policies.
